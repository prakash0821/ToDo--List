# ToDo-List

This is a simple, responsive to-do list web application built entirely with HTML, CSS, and vanilla JavaScript. The app allows users to add, edit, mark as completed, and delete tasks directly in the browser without any backend integration.

Key Features:
Add New Tasks: Users can input and add tasks via a text input field and submit button.

Mark as Completed: Click on a task to toggle its completed status (usually shown with a line-through or color change).

Edit Tasks: Double-click or use an edit button to modify existing tasks.

Delete Tasks: Remove tasks with a dedicated delete button/icon.

Persistent UI: Tasks remain visible until the page is refreshed or closed (no local storage or backend).

Responsive Design: Clean layout adaptable to mobile and desktop screens.

Technologies Used:
HTML for structure

CSS for styling and layout

JavaScript (ES6) for interactivity and DOM manipulation

This app is ideal for beginners learning frontend development and JavaScript DOM handling.
